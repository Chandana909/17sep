# ADR 0004: A constrained rule DSL is the only thing agents may propose

**Status:** accepted

**Decision.** Detection rules are conjunctions of conditions over registered signals, with a capped number of conditions. There is no code and no free expressions. Discovery synthesises the smallest rule that keeps labelled precision and stays on activity production does not already catch. Duplicates and patterns already covered are rejected.

**Consequences.** Every candidate can be validated, replayed, diffed, attacked with counterexamples and shadowed with the same engine that runs production.
